Analyste de football

Un système génératif qui se mesure
Il répond sur les lois du jeu en citant ses sources,
et prépare des rapports d'avant-match à partir de données ouvertes.
Quatre niveaux, comparés sur le même protocole
Niveau 0
LLM seul
  • Un prompt soigné
  • Ni documents, ni outils
  • La référence à battre
Niveau 1
RAG
  • Cherche dans les lois du jeu
  • Cite ses sources
  • S'abstient si rien n'est trouvé
Niveau 2
Agent
  • Neuf outils sur les données de matchs
  • Boucle écrite à la main, bornée
  • Action validée par l'utilisateur
Niveau 3
Agent avec plan
  • Décide avant d'agir
  • Demande une précision si besoin
  • Publication gardée par le plan
80 cas de test : chaque niveau doit prouver ce qu'il apporte, et ce qu'il coûte
